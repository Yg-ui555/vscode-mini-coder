02 / 快捷

4 个斜杠命令，替代 30 次点击。

高频操作一键触发。不用每次写"请帮我跑测试然后 commit 然后看错题本"。 `/test` `/commit` `/notes` `/solve`，输完按回车，剩下交给 Mini-Coder。

/test

跑测试

检测项目类型 → 自动 pytest / npm test，返回 X passed / Y failed

/commit

中文 commit

git diff → LLM 看改动 → 输出 功能: / 修复: / 重构: 中文格式

/notes

错题本

读 .notes/今天.md，回顾今天改了什么、踩了什么坑

/solve

刷 LeetCode

fetch 题目 → 自动写解法 → 加测试 → 归档错题本

在 Webview 输入框输入：

03 / 自动

保存测试文件 → 自动跑 → 失败 → AI 自动修。

别人让你"改完自己跑测试"，Mini-Coder 直接帮你跑。 失败的用例会让 AI 看错误日志 → 改源代码 → 再跑一遍 → 通知你结果。 一晚上少 5 分钟，一年 30 小时。
