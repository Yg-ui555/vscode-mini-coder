# 任务：给 `validateUsername` 补上输入校验

## 当前状态

`username.js` 里的 `validateUsername` 只检查了长度，遇到非法输入会抛异常或返回错误结果。

## 你要做的

让它在返回 `true` / `false` 之前先校验：

1. 必须是字符串（传数字、null、undefined 都应返回 `false`，不能抛异常）
2. 长度必须在 3~20 之间（**包含** 3 和 20）
3. 只能包含英文字母、数字、下划线
4. 不能以下划线开头或结尾

## 约束

- **不要修改已有的长度校验逻辑**
- 不要修改导出方式（`module.exports = { validateUsername }`）
- 不要删除任何已有代码

## 完成标准

`check.js` 会跑一组断言，包括正常的、边界的、和非法输入的。全部通过才算完成。
