# 内核工具库

一个分层的多模块工具库：

| 层 | 目录 | 说明 |
|---|---|---|
| core | `src/core/` | 无业务语义的通用函数 |
| internal | `src/internal/` | 内部能力，**不承诺**稳定性 |
| public | `src/public/` | 对外承诺稳定性的 API |
| api | `src/api/` | 对外入口，按用途分成几个分册 |

## 分层规矩

每一层都可以转发下一层的符号，但**转发不等于透传** ——
某一层可能对某些符号做了替换（历史原因）。

所以"我改了 core 里的函数，为什么对外的行为没变"这类问题，
答案通常在中间某一层的转发文件里。

## 消费方

- `src/features/` —— 业务功能
- `src/widgets/` —— 展示组件
- `src/utils/` —— 工具层
