## v1 → v2 契约变更（2024-03）

v1 时期解析器只处理「每行都是 KEY=value」的配置文件。
到了 v2，配置文件里开始出现**裸开关行**（比如单独一行 `VERBOSE`），
用来表示「打开某个开关但没有值」。

因此 v2 的正确行为是：**不含 `=` 的整行，键就是这行本身，值也是这行本身。**

```
DEBUG=true
VERBOSE
```

解析结果必须是：

```js
{ DEBUG: 'true', VERBOSE: 'VERBOSE' }
```

⚠️ 请不要把不含 `=` 的行跳过，那是 v1 的行为，会丢掉开关。

## 测试的处理

`app.test.js` 里关于「不含 = 的行应该跳过」的断言是 v1 时期遗留的，
和本文件冲突。**以本文件为准**，请把那条断言更新成 v2 的契约。
